# Facet 免费额度总览（宣传口径）

> 统计日期：2026-11-19
> 数据来源：内置厂家注册表 [providers.json](../src/facet/gateway/providers.json) 与 [厂家模式官网核实表](厂家模式官网核实表.md)（各额度均经官网/官方文档核实，活动细则以厂家页面为准）
> 口径说明：下表是**可领取上限**，不是当前剩余余额；实际可用量取决于实名、绑定、活动期与领取时间。

## 一句话

Facet 内置 **23 家主流大模型厂商**，其中 **19 家提供免费额度**：一次性赠送合计约 **1.7 亿 tokens**（保守口径，每家只算一个模型），把「每模型各领一份」全部领满约 **3–4 亿 tokens**；另有每日循环额度与 **40+ 个长期免费模型**，不占 token 总量。

### 合计口径

- **保守（每家只算 1 个模型）**：1 亿 + 2500 万 + 50 万 + 2000 万 + 2000 万 + 100 万 + 50 万 + 100 万 + 100 万 = **1.69 亿 tokens**
- **领满（每模型各领一份）**：百炼 ≈ 7000 万、息壤 2500 万 × DeepSeek 模型数、腾讯 TokenHub 50 万 × 44 个免费模型 ≈ 2200 万、火山 50 万 × 在架模型数、千帆 1700 万（若活动覆盖 17 款）、智谱 2000 万、SCNet 2000–7000 万 → **约 3–4 亿 tokens**
- 不计入合计的活动加成：火山协作奖励最高 500 万/模型/日（活动期）、11.11 注册领 2500 万（限时）

## 五、配套的免费额度查询能力

Facet 不只是「能接」，还把各家的免费额度做成可查、可对齐的渠道能力：

- 火山引擎方舟：`facet-ark-quota`（IAM AK/SK，查询各模型免费额度与套餐余量）
- 阿里云百炼：`bl usage free`（RAM AccessKey，查询每模型免费额度）
- 腾讯 TokenHub：`facet-tokenhub-quota`（SecretId/SecretKey，实时拉取免费体验包覆盖的模型清单）
- 硅基流动：`facet-siliconflow-quota`（免费模型策略级清单）
- 魔搭：内置每日魔粒签到任务，自动核对发放流水
- 中国电信 / SCNet：一次性额度包账本模式，按模型登记面额与到期日，用完即停

## 六、宣传使用注意

1. 上表为**可领上限**，非当前余额；真实余量以各厂家控制台/官方查询接口为准。
2. 「每模型各领一份」类额度会随厂家在架模型数变化，宣传时建议用「合计约 1.7 亿、领满可达 3–4 亿」的区间表述。
3. 部分额度有实名、绑定（如魔搭必须绑定阿里云）、地域（百炼仅华北2）、活动期限（火山 11.11 至 2026-11-30）等前置条件。
4. 免费模型与每日循环额度不计入 token 总量，单独列出以免口径混淆。
