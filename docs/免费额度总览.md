## 五、配套的免费额度查询能力

Facet 不只是「能接」，还把各家的免费额度做成可查、可对齐的渠道能力：

- 火山引擎方舟：`facet-ark-quota`（IAM AK/SK，查询各模型免费额度与套餐余量）
- 阿里云百炼：`bl usage free`（RAM AccessKey，查询每模型免费额度）
- 腾讯 TokenHub：`facet-tokenhub-quota`（SecretId/SecretKey，实时拉取免费体验包覆盖的模型清单）
- 硅基流动：`facet-siliconflow-quota`（免费模型策略级清单）
- 魔搭：内置每日魔粒签到任务，自动核对发放流水
- 中国电信：一次性额度包账本模式，按模型登记面额与到期日，用完即停

## 六、宣传使用注意

1. 上表为**可领上限**，非当前余额；真实余量以各厂家控制台/官方查询接口为准。
2. **宣传 ≠ 到手**：teleAI 控制台实领每模型 1 亿 + Xing4.1-Preview 专用 10 亿 0 元购资源包（2026-11-27 核对，此前「实到 300 万」记录作废）；SCNet 赠送 1 亿仅限官方客户端、API 无法消耗（2026-11-27 已移除支持）——对外表述按**实到口径**（合计约 11.5 亿、领满约 16.6 亿），避免被观众实测打脸。
3. 「每模型各领一份」类额度会随厂家在架模型数变化，宣传时建议用「合计约 11.5 亿、领满可达约 16.6 亿」的区间表述。
4. 部分额度有实名、绑定（如魔搭必须绑定阿里云）、地域（百炼仅华北2）、活动期限（火山 11.11 至 2026-11-30）等前置条件。
5. 免费模型与每日循环额度不计入 token 总量，单独列出以免口径混淆。
