> 配套 [demo-video-plan.md](demo-video-plan.md) 使用。口播全文与底稿逐字一致；本文件补齐每个镜头的具体操作步骤、前置数据与坑位提醒，照着录即可。

## 〇、拍摄总设置

| 项 | 要求 |
|---|---|
| 录屏 | 1080p、30fps 起；系统缩放 100–110%；浏览器字体放大到手机预览也看得清 |
| 通知 | 开启系统勿扰（Win+N），关闭所有弹窗来源；托盘只留必要图标 |
| 浏览器 | 独立窗口、无痕模式（书签栏干净），供后续镜头备用；开场 PPT（`docs/Facet免费额度全景.pptx`）提前打开到放映状态 |
| 终端 | 字体 ≥18pt、深色主题；保持一个窗口 |
| 主题 | 控制台全程同一主题（浅色或深色，别中途换） |
| 素材文件 | 每镜头单独存一条：`L01.mp4` … `L09.mp4`；废条保留别删，后期好挑 |
| 配音 | 后期录；镜头内留白处按脚本标注停顿 |

## 〇½、镜头 0：开拍前环境准备（不录入片）

全新安装没有历史数据，台账、时间线、备份、建议都要现场攒。按顺序做：

| 步 | 操作 | 目的 |
|---|---|---|
| A1 | 双击 `Facet-Setup-1.0.2.exe` 完成全新安装（这步留给镜头 2 正式录；先用另一份安装包装好练手环境也可以，但正式片用全新安装实录） | — |
| A2 | 向导配好 **2–3 个可用渠道**（至少 2 个当场测通；选 1 个稳定的当「主力」，1 个当「替身」） | 镜头 4 切换的底气 |
| A3 | 用 Codex（接好 Facet）正常跑 **3–5 轮对话** | 攒请求记录、额度台账 |
| A4 | 自维护页 → 「立即体检」跑一次，出第一份报告 | 镜头 6 的报告 |
| A5 | **制造「一键采纳」建议**：渠道配置 → 编辑主力渠道 → 把模型映射删到只剩 1 个 → 保存（自动产生一份备份）→ 托盘退出 Facet 再启动（清掉目录缓存）→ 自维护 → 立即体检 → 此时应出现「上游新增模型」建议，且带**「一键采纳」按钮** | 镜头 6/7 的核心素材。采纳后产生的配置备份正好供镜头 7 用 |
| A6 | 免费模型页 → 点「立即对齐厂家额度」，确认余量数字可读 | 镜头 5 画面 |
| A7 | **镜头 4 排练 2 遍**：禁用渠道 → 再发请求 → 确认切换成功、时间线可读。注意 **30 分钟会话粘滞**——排练后重启实例或等窗口过期再正式录 | 高潮一次录成 |

> 坑：如果 A5 没出「一键采纳」建议（说明目录里没有未映射模型），重复 A5 的「删映射 → 重启 → 体检」，直到按钮出现为止。控制台的「一键采纳」只对「上游新增模型」类建议渲染。

## 镜头 2 · 一键安装 + 新手向导（1:00–1:45）

**画面**：资源管理器双击 `Facet-Setup-1.0.2.exe` → 安装完成 → 开始菜单启动 Facet（托盘出现）→ 浏览器打开 `http://127.0.0.1:8787/` → 新手向导全流程。

**操作步骤**：
1. 双击安装包，等进度条走完（这段可后期 2–4 倍速）；
2. 开始菜单点 Facet → 托盘图标出现；
3. 浏览器开 `http://127.0.0.1:8787/` → 向导自动弹出；
4. 按向导走：设管理密码 → 选偏好（免费优先）→ 挑一家有免费额度的厂家 → 粘贴 API Key → 点测试（**当场发真实请求**，成功标记要给特写）→ 保存 → 自动生成调用密钥；
5. 向导完成页出现 curl 示例（可顺手复制，不执行）。

**口播**（约 150 字）：

> Facet 是装在你自己电脑上的 AI 网关。一句话：**把一堆零散、随时会挂的渠道，变成一个稳定不掉线的本地统一入口。**先看安装：Windows 双击安装包，装完打开控制台，跑一遍新手向导——设个管理密码，挑一家你常用的厂家，把 Key 粘进去，它当场发一条真实请求帮你验证通不通，通了自动生成调用密钥。不用啃文档，几分钟配好第一个渠道。

**字幕/标注**：「Windows 一键安装 · 几分钟配好」

**注意**：
- Key 粘贴前把输入框内容涂掉或用假 Key 演示粘贴动作、真 Key 用剪贴板（**别让真 Key 出现在画面里**）；
- 测试按钮转圈→成功的瞬间是本镜头的记忆点，别快剪掉。

## 镜头 3 · 统一入口（1:45–2:00）

**画面**：控制台「模型接入 → 接入配置生成」选 Codex → 复制配置 → 粘进 `~/.codex/config.toml`（文件内容特写 1–2 秒）→ 终端跑 Codex 发一条任务 → 正常返回。

**操作步骤**：
1. 控制台「模型接入 → 接入配置生成」→ 下拉选 Codex → 点复制；
2. 打开 `~/.codex/config.toml` 粘贴（`model=facet-auto`、`base_url=http://127.0.0.1:8787/v1`、`wire_api="responses"`），保存；
3. 终端启动 `codex`，发一条小任务（如「用 Python 写个判断质数的函数」），看到正常输出即停。

**口播**（约 60 字）：

> 接下来，Claude Code、Codex，或者 OpenClaw、WorkBuddy 这类跑任务的 agent 服务——把地址指到 Facet 就行，使用习惯什么都不用改，以后所有请求都从这一个门进。

**字幕/标注**：「所有 AI 工具指向一个入口 · Claude Code / Codex / OpenClaw / WorkBuddy」

**注意**：
- 本片高潮演示用 Codex（协议直通、配置现成）。若想画面里出现 Claude Code，需先把 anthropic 渠道搭通（当前 `claude-plan` 未启用），否则不要拍它；
- 屏幕右上可贴小角标列工具名（Claude Code、Codex、OpenClaw、WorkBuddy），口播点名时逐个点亮。

## 镜头 4 · 自动容灾 + 尝试时间线（2:00–3:00，全片高潮）

**画面**：Codex 正常跑任务 → 切控制台禁用当前渠道 → 回终端再发一条，照常成功 → 控制台「请求日志」点开该请求 → 尝试时间线特写。

**操作步骤**：
1. 终端 Codex 跑一条任务（如「把这个函数改成支持负数」），确认成功——此时它走的是主力渠道；
2. （可选确认）控制台「运行状态」页指出当前在用的渠道；
3. 控制台「渠道配置」→ 找到主力渠道 → 点「禁用」→ 保存（热加载即生效，画面给特写）；
4. 切回终端 → **再发一条任务** → 照常返回成功；
5. 控制台「请求日志」→ 点开刚才那条 → 详情弹窗里的**尝试时间线**：先试了谁、为什么没成、切到谁、谁接住——逐行特写；
6. 结束后记得把主力渠道重新启用（录制素材之外的动作，别拍进去）。

**口播**（约 200 字）：

> 我最想给你看的是这个。现在这条对话正在走 A 渠道——我把 A 渠道直接停掉。你看，对话没有断，Facet 自动把请求切到了下一个可用渠道：不换 key、不改配置、不中断。这背后是排好序的路由链，哪个渠道稳、哪个适合长任务，都提前排好了。口说无凭，点开这条请求的详情，里面有一条尝试时间线：先试了谁、为什么没成、又切到谁、最后谁接住，每一步都记着。容灾不是黑箱，是看得见的事实。

**字幕/标注**：「不换 key · 不改配置 · 不中断 · 每一步看得见」

**注意**：
- 「停掉」用控制台禁用（画面直观、可逆），别用断网（不可控）；
- 切换发生在**下一条请求**，步骤 4 的成功返回就是高潮帧，镜头别抖；
- 时间线弹窗里若有真渠道名/密钥痕迹，后期打码或用演示渠道名；
- 步骤 5 时间线逐行滚动的节奏跟口播「先试了谁…又切到谁…」对齐。

## 镜头 6 · 自维护体检 + 一键采纳（3:40–4:15）

**画面**：控制台「自维护」页：体检报告 → 「上游新增模型」建议 → 点「一键采纳」→ 采纳成功提示。

**操作步骤**：
1. 打开「自维护」页，展示体检报告概览；顺手指一下后台任务列表里的「能力分刷新」——每周自动抓取公开榜单最新分数，不用手动更；
2. 找到「上游新增模型」建议（镜头 0 的 A5 造好的），指着建议里的模型名念一下；
3. 点「一键采纳」→ 成功提示特写；
4. （顺手）指一下「忽略」按钮——口播「不想采纳可以忽略」在镜头 7，这里不必点。

**口播**（约 80 字）：

> 更省心的是，它会自己照顾自己：定期给所有渠道做体检，模型下线了自动换到同类可用的，换完还发一条真实请求验证——验不过就报警，绝不装没事。连能力榜单都每周自动刷新，新分数直接覆盖，不用你重装。

**字幕/标注**：「自动体检 · 一键修复 · 修完自证可用」

**注意**：采纳后配置自动产生一份新备份（`router.json.suggestion.bak`），正好是镜头 7 的素材——两镜头连贯拍，中间不停机更好。

## 镜头 7 · 信任机制：备份 + 可回滚（4:15–4:40）

**画面**：控制台「配置备份」列表 → 指最近几条备份（含刚才采纳产生的）→ 选中一条 → 点「恢复」→ 恢复成功 → （可选）指「忽略」按钮。

**操作步骤**：
1. 「自维护 → 配置备份」页，列表里指出刚才一键采纳自动生成的备份条目（时间对得上）；
2. 鼠标悬停「恢复」按钮 1–2 秒（演示到位即可，**不真恢复**——真恢复会回滚掉采纳结果，后面镜头用不上）；
3. 回自维护页指一下建议旁的「忽略」按钮。

**口播**（约 70 字）：

> 它敢动手，你也敢放心：所有改动之前自动存快照；新模型的建议，不想采纳可以忽略；配置真改坏了，一键恢复原样。

**字幕/标注**：「改前自动备份 · 可忽略 · 可恢复」

**注意**：口播说「一键恢复」但画面只悬停不点击，后期字幕补一句「（演示）」或口播改「真改坏了，一键就能恢复」——避免观众较真为什么不点。若想真点：先备份当前配置文件，恢复后用配置导出再还原回来（多两步，可不录）。
