## 二、主要功能（在线表格「软件的主要功能」栏，约 300 字以内可直接粘贴）

Facet 模型路由网关软件是一款面向大模型应用的多上游统一接入与智能路由软件。软件以单一入口对外提供 OpenAI 与 Anthropic 两种兼容协议，将多个模型服务渠道（云厂商 API、订阅账号桥接、免费额度服务）聚合为一个逻辑网关，并根据渠道健康度、配额状态与请求特征自动选择上游，实现故障自动转移、额度自动回避与免费额度优先使用。软件提供三种内置模型别名：facet-auto（自动路由）、facet-cheap（低成本优先）、facet-agent（面向工具调用的动态模型集合）；其中 facet-agent 由网关在运行期从各渠道目录中筛出支持工具调用、可正常响应的模型并动态选取，调用方无需关心具体模型名。软件自带可视化管理控制台，支持渠道与路由配置、模型目录同步、健康探针、稳定性评分、请求审计日志、用量统计和免费额度对齐等自维护能力。

## 三、软件的技术特点（约 200 字以内可直接粘贴）

1. 纯 Python 标准库实现，无第三方运行时依赖，单进程即可部署，同时提供 Docker 镜像与挂载式数据目录。
2. 协议不转换：OpenAI 请求只路由到 OpenAI 渠道、Anthropic 请求只路由到 Anthropic 渠道，避免跨协议语义失真。
3. 多级故障转移：按「钉住渠道 → 免费优先 → 稳定性评分」排序候选，失败自动切换；配额耗尽按 Retry-After / reset 头计算冷却窗口，支持半开探测。
4. 稳定性评分机制：每渠道每模型独立记分（成功加分、失败扣分、按时间衰减），失败模型自然沉底，避免反复命中坏模型。
5. 动态模型集合（facet-agent）：结合内置模型能力注册表与渠道实时目录，剔除明确不支持工具调用与已被验证失效的模型，调用方只填别名。
6. 密钥安全：配置文件仅保存 `env:变量名` 引用，真实密钥放在环境变量；控制台对密钥回显打码。
7. 全链路可观测：每次请求记录渠道、模型、状态、耗时、用量与路由原因，支持按天统计与 CSV 导出。

## 四、软件用途（约 100 字）

用于个人开发者与团队在本地或内网环境中统一接入多家大模型服务，降低多密钥、多协议、多额度管理的复杂度，并在上游限流、超额或故障时保持业务连续可用。
