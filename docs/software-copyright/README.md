# 软件著作权登记材料包

本目录用于 **计算机软件著作权登记（软著）** 的申请材料准备。所有文件均以本项目（Facet 模型路由网关软件）为对象，可按需替换其中的占位内容后直接提交。

## 一、材料清单

| 编号 | 文件 | 用途 | 是否需盖章 |
| --- | --- | --- | --- |
| 01 | `01-登记信息表.md` | 在线申请表逐项填写内容（软件全称、版本、环境、功能、技术特点等） | 否（在线填报） |
| 02 | `02-软件说明书.md` | 软件说明书 / 用户手册底稿（文档鉴别材料来源） | 是（每页或骑缝） |
| 03 | `03-源代码文档规范.md` | 源代码文档的排版要求与生成方法说明 | 否 |
| — | `gen_copyright_docs.py` | 生成 `output/` 下的 .docx 鉴别材料 | 否 |
| — | `output/软件说明书-V1.0.docx` | 文档鉴别材料（前 30 页 + 后 30 页） | 是 |
| — | `output/源代码文档-V1.0.docx` | 源程序鉴别材料（前 30 页 + 后 30 页） | 是 |

此外还需申请人自行准备（本目录不生成）：

- **身份证明**：企业提交营业执照副本复印件（加盖公章）；个人提交身份证正反面复印件。
- **申请表**：在中国版权保护中心「软件著作权登记系统」在线填写后打印、签章。
- **代理委托书**：委托代理机构办理时提供。

## 二、提交口径（2023 版登记办法口径）

1. **源程序鉴别材料**：提交源程序前 30 页 + 后 30 页，每页不少于 50 行（除最后一页外）；不足 60 页的全部提交。页眉应含软件全称、版本号、页码。
2. **文档鉴别材料**：提交文档前 30 页 + 后 30 页，每页不少于 30 行；不足 60 页的全部提交。
3. 页眉、页码连续编号，不跳页、不留空白页。
4. 材料按 A4 纸单面打印，装订成册。

## 三、使用步骤

```bash
# 1. 在本目录下生成 docx 鉴别材料（只依赖 python-docx）
python docs/software-copyright/gen_copyright_docs.py

# 2. 生成结果
#    output/源代码文档-V1.0.docx   60 页，每页 50 行（前 30 页 + 后 30 页）
#    output/软件说明书-V1.0.docx   含封面、页眉与页码，页数由 Word 渲染确定
```

脚本运行时会打印页数、每页行数与最长行宽。当前产物已生成，可直接打开复核。

生成后请人工检查：

- 软件全称、版本号是否与申请表完全一致（三个材料必须逐字一致）。
- 页眉、页码是否从第 1 页连续到最后 1 页。
- 源代码文档中是否存在空页（脚本已自动删除空行，每页固定 50 行）。
- 说明书中的「〔截图：xxx〕」占位是否已替换为实际运行截图。

## 四、需要替换的占位内容

| 占位 | 出现位置 | 说明 |
| --- | --- | --- |
| `【著作权人】` | `01-登记信息表.md`、说明书封面 | 公司全称或个人姓名 |
| `【开发完成日期】` | `01-登记信息表.md` | 默认按 2026-11-10 填写 |
| `【首次发表日期】` | `01-登记信息表.md` | 未公开发表的填「未发表」 |
| `【联系人 / 电话 / 邮箱】` | `01-登记信息表.md` | 申请人联系方式 |

## 五、注意事项

- **软件全称**建议采用「品牌 + 功能 + 软件」结构，本材料统一使用「Facet 模型路由网关软件」，简称「Facet 网关」，版本「V1.0」。改名时三份材料需同步修改。
- 源代码文档只收录**自主开发**的源代码（`src/planrouter`、`src/facet`），不包含第三方库、测试代码与构建脚本，避免权属争议。
- 说明书中引用的截图位置以「〔截图：xxx〕」标注，正式提交前请截取实际运行界面替换。
- 若软件包含多个版本迭代，登记版本应与实际交付版本一致，避免后续变更登记。
