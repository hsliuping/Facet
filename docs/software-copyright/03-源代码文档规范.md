# 源程序鉴别材料规范与生成方法

本文件说明源程序鉴别材料（源代码文档）的登记要求、收录范围、排版参数，以及本目录下生成脚本的用法。文档鉴别材料（软件说明书）的生成方式一并说明。

## 一、登记要求

依据《计算机软件著作权登记办法》及中国版权保护中心现行受理口径：

1. **提交范围**：源程序前 30 页 + 后 30 页；源程序不足 60 页的，全部提交。
2. **每页行数**：每页不少于 50 行（最后一页可例外）。
3. **页眉**：应包含软件全称、版本号、页码，页码连续编排。
4. **一致性**：材料中的软件全称、版本号必须与申请表、说明书完全一致（本材料统一为「Facet 模型路由网关软件」「V1.0」）。
5. **形式**：A4 纸单面打印，装订成册；每页或骑缝加盖著作权人公章（个人申请签字）。

文档鉴别材料（说明书）的对应要求为：前 30 页 + 后 30 页，每页不少于 30 行；不足 60 页的全部提交。

## 二、收录范围

源程序只收录**著作权人自主开发**的代码，避免混入第三方代码引起权属争议。

| 收录 | 路径 | 说明 |
| --- | --- | --- |
| 是 | `src/planrouter/*.py` | 网关主体：路由、调度、渠道管理、控制台后端、维护任务 |
| 是 | `src/facet/*.py` | 命令行入口与包装层 |
| 否 | `src/facet/_version.py` | 构建时自动生成，非手工编写 |
| 否 | `tests/` | 测试代码，不属于软件本体 |
| 否 | `tools/`、`docker/` | 构建与部署脚本 |
| 否 | `src/planrouter/static/*` | 前端资源，如需登记可另附，不并入源程序 |
| 否 | 任何第三方库、随包数据文件 | 非自有代码 |

统计口径：`src/planrouter` 与 `src/facet` 的 Python 源文件合计约 8,900 行（含空行与注释），剔除空行后约 7,900 行；按每页 50 行的密度排版，足够支撑「前 30 页 + 后 30 页」的提交口径。

## 三、排版参数

脚本已按下列参数生成，无需手工调整：

| 项目 | 取值 |
| --- | --- |
| 纸张 | A4（21 × 29.7 cm），纵向 |
| 页边距 | 上 2.0 cm、下 2.0 cm、左 2.0 cm、右 1.8 cm |
| 页眉 | 左：软件全称 + 版本；右：「第 X 页」，页眉距顶端 1.0 cm |
| 正文字体 | 西文 Courier New 9 pt，中文 宋体 9 pt |
| 行距 | 固定值 11 pt（保证每页 50 行不下溢） |
| 每页行数 | 每页固定 50 行，页末强制分页 |
| 空行 | 自动删除空行；保留注释行与缩进 |

排版容量校验：页面正文高度 25.7 cm（约 728 pt），50 行 × 11 pt = 550 pt，余量约 16 行，因此个别超长代码行自动折行也不会挤掉下一行、导致页内不足 50 行。

## 四、生成方法

在项目根目录执行：

```bash
python docs/software-copyright/gen_copyright_docs.py
```

脚本只依赖 `python-docx`（未安装时执行 `pip install python-docx`），输出到本目录的 `output/`：

| 产物 | 内容 |
| --- | --- |
| `output/源代码文档-V1.0.docx` | 源程序前 30 页 + 后 30 页，共 60 页，每页 50 行 |
| `output/软件说明书-V1.0.docx` | `02-软件说明书.md` 转成的带封面、页眉、页码的正式文档 |

脚本运行后会打印每个文档的页数、每页行数校验结果与最长行宽，若校验不通过会给出提示。

## 五、生成逻辑说明

1. **拼接**：按目录顺序读取 `src/planrouter`、`src/facet` 下的全部 `.py` 文件，每个文件前插入一行 `# ── 文件：相对路径 ──`，便于核对代码出处。
2. **清洗**：删除纯空行，保留缩进、注释与文档字符串，不做任何语义删改。
3. **截取**：清洗后若总行数超过 3000 行（60 页容量），取前 1500 行作为前 30 页，取末 1499 行加一行省略说明作为后 30 页。
4. **分页**：每 50 行为一页，页末插入分页符，保证每页满 50 行。
5. **页码**：页眉中的页码使用 Word 域（`PAGE`），打印或打开文档时自动连续编号。

## 六、提交前自检清单

- [ ] 页眉中的软件全称、版本号与申请表、说明书逐字一致。
- [ ] 页码从第 1 页连续到最后一页，无跳页、无空白页。
- [ ] 每页行数不少于 50 行（最后一页除外）。
- [ ] 源程序页码与说明书中标注的页数口径一致。
- [ ] 已删除或替换说明书中的「〔截图：xxx〕」占位。
- [ ] 封面「【著作权人】」已替换为实际名称。
- [ ] 装订、盖章完成，纸质材料与电子文档内容一致。

## 七、常见退回原因

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 补正通知书要求补交源程序 | 页数不足 60 页却只提交了部分，或每页不足 50 行 | 按本文口径重新排版 |
| 材料名称不一致 | 申请表、说明书、源程序页眉三者名称写法不同 | 统一为「Facet 模型路由网关软件」 |
| 页眉缺失页码 | 手工排版时未插入域页码 | 使用本脚本生成 |
| 权属存疑 | 源程序中混入第三方库代码 | 只收录自主开发目录 |
