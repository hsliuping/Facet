# Facet 用户手册

按任务组织的使用手册：每个任务一节，跟着做就能完成。各功能的完整说明在控制台对应页面里，页面顶部都有一段「这是什么、怎么用」。

> 如果你只想快速把工具接上调模型：跳到[任务 2](#任务-2把工具接进来)。

---

## 任务 1：第一次部署

**目标**：装好 Facet，打开控制台，完成新手向导。

1. **安装并启动**
   - Windows：运行安装包（`Facet-Setup-*.exe`），安装后从开始菜单启动 Facet（托盘图标常驻）。
   - 源码 / 容器：`pip install .` 后执行 `facet`；或直接运行镜像，控制台在 `http://127.0.0.1:8787/`。
2. **打开控制台**：浏览器访问 `http://127.0.0.1:8787/`。首次启动没有管理密码，页面会引导你设置一个。
3. **跑新手向导**：点右上角「快速开始」，按步骤完成：偏好（免费优先 / 付费）→ 选厂家 → 粘贴 API Key → 测试保存渠道 → 生成网关调用密钥。每一步都有验收，测试通过才算完成。渠道测试会自动拉取厂家模型目录、逐个试到打通为止（优先该厂家自有模型），页面实时显示每个模型的测试结果——某个模型在上游已下线（404）不会卡住向导；若全部失败或提示 Key/账号错误，再回上一步检查 Key。
4. **验证**：向导最后会给出可直接运行的 curl 示例，跑通即部署完成。

**下一步**：[任务 2](#任务-2把工具接进来) 把你的工具接进来。

## 任务 2：把工具接进来

**目标**：让 Claude Code / Codex / Trae / Cline / OpenCode 等工具经由 Facet 调模型。

Facet 暴露两种协议，端点都在网关地址下：

- OpenAI 协议：`http://127.0.0.1:8787/v1/chat/completions`（兼容 `/v1/models`）
- Anthropic 协议：`http://127.0.0.1:8787/v1/messages`

三个要素（控制台「接入信息」页一键复制全部内容）：

| 要素 | 填什么 |
| --- | --- |
| Base URL | `http://127.0.0.1:8787/v1`（OpenAI 协议）或网关地址（Anthropic 协议） |
| API Key | 「API Keys」页生成/复制的调用密钥 |
| 模型名 | 精确模型名，或 `facet-auto` / `facet-cheap` / `facet-free` 让网关自动挑 |

各工具的整段配置文件模板在控制台「模型接入 → 接入配置生成」，选工具直接复制粘贴。协议细节、流式行为与错误码见「接入文档」页。

## 任务 3：省钱——免费额度与付费预算

**目标**：尽量用免费模型，付费调用有预算上限。

- **看免费模型**：「免费模型」页列出所有免费渠道的模型、**能力分**、剩余额度、厂家限速，可按能力分排序。能力分来自公开评测（Vals Terminal-Bench 4.0 等），每周自动刷新；额度用尽的模型会被网关立即停用，不会悄悄转成计费。
- **自动省钱**：把工具的模型名填 `facet-cheap`，网关在可用免费模型里自动挑一个；免费不可用时按路由链落到付费档。
- **策略预设**：「路由链」页顶部的「免费/付费策略预设」一键切换「只用免费 / 免费优先 / 付费优先」，切换前有实时预览。
- **付费预算**：付费渠道可设 `paid_budget_tokens` 月度预算，接近预算会触发告警通知。
- **额度对齐**：免费额度显示「厂家额度未同步」时，点「立即对齐厂家额度」拉取厂家真实余额。

## 任务 4：日常运维

**目标**：确认服务健康，看用量，留好退路。

- **健康一眼看**：「仪表板」每 5 秒刷新：渠道状态分布、订阅余量、近 7 天趋势。
- **用量报表**：「用量报表」按天/按月看请求数与 tokens，明细里的渠道名可点击跳到「渠道配置」并预填筛选；「成员用量」看团队各成员的消耗；两页都支持导出 CSV 留档。
- **改配置**：渠道编辑即改即生效（热加载），无需重启。「路由链」定义内部调度（`facet-auto` 等不指定具体模型）的失败切换顺序；直接指定模型名时，网关按渠道配置顺序在映射了该名字的渠道间转移，同名渠道全部不可用则如实报错，不会换模型。
- **备份**：自动运维改写配置前都会自动备份（`router.json.<操作>.bak`），「自维护 → 配置备份」可一键恢复。
- **整包备份**：重要变更前可在「自维护 → 整机迁移」导出完整迁移包（见[任务 6](#任务-6整机迁移换机器重装系统)）。
- **能力分刷新**：「自维护」页的「能力分刷新」任务每周从公开榜单抓取最新 Terminal-Bench 4.0 分数并覆盖到本地，新分数无需重装即生效；也可点「刷新能力分」立即拉取。开关在配置 `defaults.benchmark_refresh_hours`（默认每周，0 关闭）。

## 任务 5：排障

**目标**：请求失败时自己定位问题。

1. **看请求日志**：「请求日志」页按状态/关键词筛选失败请求（带筛选框的页面按 `/` 可直接聚焦筛选，Esc 清空关键词）；点开一条看**尝试时间线**——每次尝试的渠道、错误与耗时，筛选结果可导出 CSV。
2. **看错误翻译**：详情弹窗会把上游报错翻译成人话，并给出修复按钮（如「去冷却」「重测该模型」），点按钮直接处理。
3. **查配置体检**：「渠道配置」页顶部横幅自动点破三类静默配置问题——同一条链里重复声明的模型名（链序靠前者优先生效，其余只是失败后备）、`env:` 密钥引用的变量没读到、把脱敏导出当配置用的 `***` 占位密钥；按提示改配置即可消除。
4. **渠道为什么被跳过**：「运行状态」页看渠道冷却原因与剩余时间；模型级问题看「自维护」的维护报告。
5. **导出诊断包**：「请求日志 → 导出诊断包」生成脱敏 JSON（密钥已掩码），可安全发给维护者求助。
6. **管理 API 报 401**：管理密钥（admin_key）与调用密钥（api_key）是两回事；控制台弹窗会提示去哪一页填写。

## 任务 6：整机迁移（换机器、重装系统）

**目标**：把整套部署原样搬到另一台机器，不用重新填渠道和密钥。

1. **导出**：旧机器「自维护 → 整机迁移 → 导出迁移包」，得到一个 zip（含配置、成员密钥、订阅账号、用量历史，**明文密钥**，请勿外发）。
2. **新机器装好 Facet** 并打开控制台，完成首次管理密码设置。
3. **导入**：新机器「自维护 → 整机迁移 → 导入迁移包」选择 zip，确认后立即生效：
   - 配置走校验管线热重载，无需重启；
   - 被覆盖的文件先备份为 `<name>.migration.bak`，随时可回退；
   - **本机管理密码保持不变**，不会被迁移包里的旧密码替换。
4. **验证**：仪表板渠道状态正常、「成员用量」能看到历史数据即迁移成功。

## 名词速查

| 名词 | 含义 |
| --- | --- |
| 渠道 | 一个上游端点（订阅桥 / API Key / 免费额度），额度耗尽自动冷却切换 |
| 路由链 | 同协议渠道的尝试顺序；`default` 链为必填 |
| 网关密钥 | 调用 `/v1/*` 用的 API Key，在「API Keys」页管理 |
| 管理密码 | 控制台与管理 API 的 admin_key，在「管理密钥」页修改 |
| 订阅 | 厂家套餐账号（如火山引擎包月），额度窗口与到期在此管理 |
| 冷却 | 渠道失败或额度耗尽后的临时停用，到期自动恢复 |
