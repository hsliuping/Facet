# Facet 1.1.0 Release Notes（中心同步与消息中心）

Facet 1.1.0 新增**中心同步与消息中心**：网关自动从中心拉取厂家注册表，自动应用可确认的渠道更新，把新厂家、额度变化、厂家下线等情报推送到控制台「消息」页，并支持托盘气泡与 webhook 通知。全程 Ed25519 验签，断网不影响转发，所有上报开关可关闭。

## 新功能

### 中心同步（每 6 小时自动拉取，带随机错峰）

- **新厂家渠道**：中心注册表里有的、你本地没有的厂家，一键添加（只接受签名情报内的厂家，界面明示目标域名，**永不预填 key**）。
- **渠道更新自动应用**：你未改动过的预置渠道（额度、免费模型清单变化）自动更新；你手动改过的渠道只提示、绝不覆盖。
- **厂家下线**：注册表标记下线的厂家在「消息」页提示，可自行决定是否停用。
- **预置模板已改动**：中心更新了预置模板而你本地渠道无指纹（旧版本安装），按「已改动」处理，只提示不覆盖。

### 消息中心（控制台新增「消息」页）

- 新厂家、渠道更新、厂家下线、新版本可用等通知统一进消息页，带未读徽标。
- 支持「全部已读」「忽略」「采用（自动应用）」，按厂家查找，已读消息进归档。
- 同步状态块显示中心地址、最近同步时间、下次同步时间与失败原因。
- Windows 托盘有新消息时弹气泡（最多 3 条，未读增加才弹）。
- 情报可转发到飞书 / 企业微信 webhook（带重试）。

### 更新通知

- 自动比对最新版本，仅当有新版本时显示横幅与下载直链（直链经验签才下发）；已是最新则完全静默。

### 心跳与控制台统计

- 匿名心跳（安装标识 + 聚合行动计数，相位错峰上报），供中心统计装机量与渠道采用情况。

## 隐私说明

- **三个上报开关**（注册表同步、情报推送、心跳统计）默认开启，可在「消息」页末尾「中心设置与隐私声明」区随时关闭；关闭后不再发出任何回传，网关功能不受影响。
- 心跳只传聚合计数，不传渠道明细与请求内容。
- 同步内容全部经 Ed25519 验签后才写入本地缓存；断网、超时、验签失败时自动沿用本地缓存，**转发请求的行为与关闭同步时完全相同**。
- 自建中心的用户可在设置里成对配置中心地址与公钥。

## 存量用户升级方法

| 渠道 | 升级方式 |
|---|---|
| Windows 安装包 | 到 [Releases](https://github.com/hsliuping/Facet/releases) 下载 `Facet-Setup-1.1.0.exe` 重装；数据在 `%LOCALAPPDATA%\Facet`，升级不丢 |
| Docker | `docker pull hsliup/facet:1.1.0`（或 `:latest`）后重启容器；数据卷保留 |
| pip | `pip install facet-models==1.1.0`（⚠️ PyPI 上的 `facet-models` 默认解析到日期版号更高的旧版 2026.9.1，务必显式锁版本） |
| 源码 | `git pull && pip install -e .` |

升级后无需任何操作：注册表同步自动开始，新功能在控制台「消息」页查看。

## 注意事项

- 旧版本安装的渠道没有预置指纹，首次同步会按「用户已改动」处理，只提示不覆盖——你的任何手动改动都不会被自动覆盖。
- 仍在运行旧镜像的 Docker 容器需重建后才包含本版本功能（`docker compose up -d --build` 或重新 pull）。
