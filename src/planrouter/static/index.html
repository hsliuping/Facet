渠道

每个渠道是一个上游端点：订阅桥、API Key 或免费额度。额度耗尽后自动冷却并切到下一档。

新增渠道请在「密钥」里直接粘贴明文 API Key；只有需要引用容器环境变量时才写 env:VAR（VAR 是变量名，不是密钥本身）。base_url 已含 /v3 等版本段时，「上游路径」留空会自动用 /chat/completions，不会重复拼出 /v3/v1/。编辑已有渠道时留空或保留 *** 表示不改动已保存的密钥。改动会自动保存并热加载，无需重启。导出文件不含密钥明文。

路由链

请求按链内顺序尝试；同一条链里的渠道必须使用相同协议。default 链为必填。

模型接入

工具端填我们自己的模型名即可，不必填 auto。任何模型名都会先按渠道声明精确匹配，匹配不上就由内部自动调度。

工具里填的模型名

这些名字始终代表「由 PlanRouter 内部选路」，可直接复制到工具的模型输入框。

内部调度

也可用 auto:<链名> / facet:<链名>，例如 facet:cheap。其它名字先精确匹配渠道 models 映射；未命中时按各渠道的 auto 映射自动调度。响应头 X-Routed-Model-Mode 会标明 auto / exact / fallback。

模型名策略

改动会自动保存并热加载，无需重启；右上角可手动立即保存。

会精确匹配的模型名

来自各渠道 models 映射中除 auto / * 之外的键；填这些名字时优先只走声明它的渠道，渠道冷却后自动回退内部调度。
