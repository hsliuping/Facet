渠道

每个渠道是一个上游端点：订阅桥、API Key 或免费额度。额度耗尽后自动冷却并切到下一档。国外上游（OpenAI、Anthropic、Grok 等）可在渠道里配置出站代理，国内直连不通时走本地代理转发。

新增渠道请在「密钥」里直接粘贴明文 API Key；只有需要引用容器环境变量时才写 env:VAR（VAR 是变量名，不是密钥本身）。base_url 已含 /v3 等版本段时，「上游路径」留空会自动用 /chat/completions，不会重复拼出 /v3/v1/。编辑已有渠道时留空或保留 *** 表示不改动已保存的密钥。改动会自动保存并热加载，无需重启。导出文件不含密钥明文。

厂家与模式

标「自定义」的厂家来自覆盖层（config/providers.json），整条覆盖内置注册表；「恢复内置」会删除该厂家的覆盖条目。获取方式：文档提取解析 docs_url 页面；接口拉取请求 models_url 返回的 JSON（支持 {"data":[{"id":...}]}、{"models":[...]} 或纯数组）；手动则不参与自动刷新。两者都填时文档提取优先。
